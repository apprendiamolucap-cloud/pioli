Perché il tuo amico non vedeva i plugin?

Spiegazione tecnica e come funziona la sincronizzazione Cloud ora

Prima: Memoria Locale del Browser (LocalStorage)

Quando caricavi un plugin prima, il file e le informazioni venivano salvati solo nella memoria privata del tuo browser. Il PC o telefono del tuo amico non aveva accesso al tuo hard disk locale, quindi per lui la lista risultava vuota.

Ora: Database Cloud Firestore Integrato

Ora il portfolio è collegato a un Database Cloud Firestore in tempo reale. Quando clicchi "Pubblica sul Cloud", i dati e il file vengono salvati online nel server centrale. Il sito di Ampliato si aggiorna automaticamente in 0.1 secondi!
