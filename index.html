Guida & Istruzioni

Come funziona questa piattaforma e come configurarla al meglio

1

Come funziona il caricamento?

Lo slot di caricamento qui sopra utilizza il browser per creare un link di download locale temporaneo (Blob URL). Quando aggiungi un file `.jar`, il plugin comparirà subito nella lista e potrai provarne il download.

I dati caricati restano nel tuo browser tramite LocalStorage.
2

Come pubblicare davvero online i plugin?

Per permettere a chiunque nel mondo di scaricare i vostri plugin, potete collegare i pulsanti a piattaforme esterne per l'hosting gratuito:

  • GitHub Releases: Caricate il sorgente e il compilato `.jar` su un repository GitHub.
  • SpigotMC / BuiltByBit: Pubblicate la risorsa ufficiale ed inserite il link diretto.
  • MediaFire / Google Drive: Alternativa rapida per condividere file `.jar`.
3

Come modificare questo sito?

Questo file è un singolo documento completo **HTML + JS + Tailwind CSS**. Potete modificarlo facilmente con **Visual Studio Code** o qualsiasi editor di testo. Per salvare permanentemente nuovi plugin nel codice predefinito, basta aggiungerli all'array initialPlugins dentro lo script JS.

4
